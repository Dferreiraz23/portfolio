# Dayane Ferreira — Portfólio (v2)

Versão ajustada com as melhorias solicitadas:

- foto profissional já preparada no layout;
- tipografia equilibrada;
- remoção dos números decorativos de página/seção;
- card de Floricultura com monograma da Esmerarse, seguindo a ideia visual do Operatto.

## Como usar sua foto

1. Coloque sua imagem na pasta `public`.
2. Renomeie para `dayane.jpg`.
3. Pronto. O site já tenta exibir essa imagem automaticamente.

Se o arquivo não existir, o layout mostra o monograma `DF` como placeholder.

## Rodar no VS Code

```bash
npm install
npm run dev
```
